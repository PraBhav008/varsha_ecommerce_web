1. COLOR PALETTE DEFINITION
================================================================================

Primary 5-Color Palette + Cream Base:
-------------------------------------
1. SKY BLUE
   - Hex: #2877A8
   - RGB: 40, 119, 168
   - CSS Var: --sky-blue
   - Role: Trust strip icons, secondary highlights, interactive accents

2. SOFT CLOUD BLUE
   - Hex: #84ADCA
   - RGB: 132, 173, 202
   - CSS Var: --cloud-blue
   - Role: Soft section tints (#84ADCA/20), card borders, input borders, dividers

3. WARM IVORY
   - Hex: #F1D9B2
   - RGB: 241, 217, 178
   - CSS Var: --warm-ivory
   - Role: Hero pill badges, secondary button surface, category tags, section tint (#F1D9B2/30), dark-section typography

4. WILDFLOWER RUST
   - Hex: #AC4811
   - RGB: 172, 72, 17
   - CSS Var: --wildflower-rust
   - Role: Primary CTA buttons (hover: #8f3a0d), active borders, star ratings, sparkle accents, footer top border

5. DEEP WALNUT
   - Hex: #371102
   - RGB: 55, 17, 2
   - CSS Var: --deep-walnut
   - Role: Brand logo, headings, body text, dark craft section (#371102 / #2B0D02), footer background (#371102 / #260B01)

6. PAGE CREAM BACKGROUND
   - Hex: #FDF9F3 (with #FAF6F0 for form inputs)
   - CSS Var: --bg-cream
   - Role: Main light page background and scrolled frosted navbar base
